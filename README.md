# Workshop 1 — CE385 JavaScript

## ข้อที่ 1 — แนะนำตัว
สร้างตัวแปรข้อมูลส่วนตัว 5 อย่าง ได้แก่ ชื่อเล่น รหัสนักศึกษา อายุ สาขาวิชา และจำนวนวิชาที่ลงทะเบียน จากนั้นใช้ console.log() และ Template Literal เพื่อแสดงผล โดยปีที่จะจบคำนวณจากปีปัจจุบันบวกจำนวนปีที่เหลือ

## ข้อที่ 2 — ชนิดข้อมูลและ typeof
สร้างตัวแปรให้ครบ 6 ชนิดข้อมูล ได้แก่ string, number, boolean, undefined, null และ array แล้วใช้ typeof ตรวจสอบชนิดข้อมูล รวมถึงทดสอบ typeof null, undefined และ NaN และการแปลงข้อความเป็นตัวเลขด้วย Number()

## ข้อที่ 3 — เครื่องคิดเลขคะแนน
คำนวณคะแนน Workshop จาก 60 คะแนนให้เป็นคะแนนเต็ม 20 คะแนน จากนั้นรวมกับ Attendance, Project, Midterm และ Final เพื่อหาคะแนนรวมและเปอร์เซ็นต์

ผลลัพธ์:
- Workshop = 16.00
- คะแนนรวม = 81.00
- คิดเป็น = 81.00%
- จากเป้าหมาย 80 = -1.00

## ข้อที่ 4 — ตัดเกรดจากคะแนน
สร้างฟังก์ชัน toGrade(score) โดยใช้ if / else if / else เพื่อตรวจช่วงคะแนนและคืนค่าเกรด A, B+, B, C+, C, D+, D หรือ F รวมถึงตรวจสอบคะแนนที่อยู่นอกช่วง 0–100

มีการทดสอบคะแนนทั้งหมด 13 ค่า ได้แก่ 95, 80, 79, 75, 70, 65, 60, 55, 50, 49, 0, -5 และ 120

## ข้อที่ 5 — ระบบสั่งอาหาร
สร้างฟังก์ชัน getMenuPrice(menu) ด้วย switch เพื่อหาราคาอาหาร และใช้ fall-through สำหรับเมนูที่ราคาเท่ากัน จากนั้นใช้ getSizeMultiplier(size) เพื่อคูณราคาตามขนาด และคำนวณราคารวมจากรายการอาหาร 5 รายการ

ตัวอย่าง:
ผัดไทย (พิเศษ) x2 = 180 บาท

## ข้อที่ 6 — ระบบตรวจสอบสิทธิ์
